# 虹彩产品演示 · 横屏试片

> **注**：本页为早期固定配乐原版记录；日常按口播配音出片（`16:9` 横屏 + `3:4` `1080×1440` 竖屏主标准、三脚架零晃动）请用模块化口播版 [prism-talk.md](prism-talk.md)。

参考用户提供的 `1920x1080 (1).mp4`。画面展示 Google AI Studio 的接入流程，长度约 33 秒。口播工作台试片采用相近的黑底、虹彩和窗口节奏，示例内容使用本地工作流。

| 时间 | 画面 |
| --- | --- |
| 0–4 秒 | 虹彩大字，发光图标一字排开，收成产品名 |
| 4–9 秒 | 暗色输入框打字，彩光铺满画面，蓝边光标点击提交 |
| 9–14.5 秒 | 输入框接入深色工作区，底部留窄虹彩边光，展示文稿和字幕状态 |
| 14.5–18.5 秒 | 蓝边光标追上放大的胶囊按钮，按钮由深转白 |
| 18.5–24.5 秒 | 黑底白色确认窗，从上半部内容推近再回到确认动作 |
| 24.5–29 秒 | 白色结果窗浮在深色工作区前，展示可预览的成片 |
| 29–33 秒 | 纯黑行动文案，再收为虹彩产品名 |

示意界面用 React 和 SVG 绘制，标题、提示词、项目名和操作文案可替换。音轨为本地合成电子配乐。规格为 1920×1080、30fps。试片入口独立保留。

在 `template/` 下运行 `npx remotion studio src/prism-preview.tsx`，选择 `PrismPromo`。

## 竖屏试片

`PrismPromoPortrait` 为 1080×1920、30fps、33 秒，和横屏共用内容配置、切点与配乐。输入框加高以容纳换行，光标分别对准提交、继续和确认按钮。白色确认窗改为纵向排版，结果窗内展示 9:16 预览。Studio 仍用 `src/prism-preview.tsx` 打开。

## 输入框承接生成态

提交后使用同一外框连续扩展为生成工作区。虹彩线框沿扩展边缘短暂显现，整屏彩光退到底边，再依次填入字幕轨与画面轨。横竖屏复用同一时间曲线，窗口尺寸和光标落点按各自画幅计算。

就绪图标使用青蓝与薄荷绿双层视频卡，主卡保留播放三角和字幕短线。发光集中在外缘，缩小时优先保住轮廓。

## 对话版 `PrismChat`（2026-11-10）

对照用户提供的 `1920x1080 (3).mp4` 重做，旧版 `PrismPromo` 保留。30 秒、1920×1080、60fps。

- 虹彩底场全程铺满并缓慢流动；暗场是中间黑、四角留虹彩，只用在品牌、大标题、一次提问和结尾短句。
- 内容是白色对话卡：用户的请求和工作台的回复一张张进来，新卡在前，旧卡上移、缩小、变虚。卡里可以带真实成片预览或逐条出现的列表。
- 开场白色粗体大字，品牌标和成片图标嵌在句子里；结尾三句短话，后半句先带虹彩色再变白，最后落到品牌。
- 段落之间用推焦（模糊加轻微缩放）衔接，不留空画面。
- 全部内容在 `template/public/prism-promo/chat.json`：品牌、称呼、每段对话、大标题、结尾短句和素材取点。超出一行的消息、过长的标题、不够长的素材会被 `validatePrismChat` 拦下。
- 配乐 `scripts/prism-chat-music.py` 从同一份配置读取段落和消息时间，换文案后重新生成即可对上。
- 预览：`npx remotion studio src/prism-preview.tsx` 选 `PrismChat`；关键帧 `npx tsx scripts/check-prism-chat.ts`。
