# 像素世界 · 竖屏版本规则

适用：用户选择“像素世界”“像素宣传片”并要求9:16，或继续编辑已确认横屏风格的竖屏版本。风格入口是 [我的视频规则](../视频规则.md)，简约工作台另选其规则。本文件只维护像素世界的竖屏规范。

## 风格与画布

- 独立的像素场景语言：信号、节点、纵深卡片、大字章节、夜景和碎片聚合。画面跟随内容选场景，工作台窗口只是其中一种素材容器。
- 成片1080×1920、30fps；像素背景原生270×480，以4倍硬边放大。文字独立排版，使用本地Fusion Pixel；英文辅助信息可用Departure Mono，保留随工程提供的字体许可。
- 夜色底、暖橙主强调、绿色连接状态；铜色光环与有序点阵构成景深。保持简约版的配色和窗口规范独立。
- 主要文字与主体使用x=72–1008范围；主体主要安排在y=200–1600。当前示例字幕顶边1600、48px、最多两行；底部约1760以后以背景为主。这是本项目构图参数，平台遮挡需用目标发布界面实看确认。
- 关键文字输出至少32px；主标题常用88–168px，口播字幕48px。景深卡片的小字是纹理，需观众阅读的信息另放稳定标题区。

## 竖屏重排配方

| 场景 | 构图与动作 |
|---|---|
| 信号开场 | 标题居中分两行，波形横穿下部；先出现主张，再让信号进入画面。 |
| 双窗口 | 上方指令、下方画面，沿中间连接线上下接力；文字打字与画面变换错时。 |
| 中心节点 | 三项在上、三项在下，核心位于纵向中部；标签错时出现，连线上有信号传递。 |
| 配音叙事 | 三角分布的模块围绕核心；在关键词处激活。结尾先拉开纵向间距，再归中为竖向工作流，核心先退场。 |
| 纵深隧道 | 消失点沿纵向中轴，前后景按深度排序；卡片可从边缘掠过，稳定标题保持可读。 |
| 大字章节 | “画面 / 节奏 / 叙事”等短词按拍切换；移动线条服务节奏，给完成后的文字留阅读时间。 |
| 双画幅展示 | 横向画面在上，竖向海报在下；分别排版，使用本身的画幅比例。 |
| 夜景过渡 | 分层楼群形成视差，信号接力进入下一场；全片至多一两个此类呼吸段。 |
| 碎片聚合 | 碎片向竖向成片轮廓聚集，先完成图形再出现结论。 |
| 片尾 | 沿用认可的方形标记、名称、承诺和链接；按竖屏重新分配位置，网址可分两行。最后一秒画面与声音共同退出。 |

## 时间与承接

- 横转竖复用已确认的叙事顺序、声音和词时间，分别设计每个场景的空间。横屏不是竖屏的裁切母版。
- 动作来自时间轴纯函数，支持跳转与倒放；随机纹理使用固定种子或确定性散列。相机和图形使用同一个画幅几何。
- 关键帧写清对象的进入、变化、退出和下一场接手位置。轮换对象承接、上下擦除、硬切等交接；有配音时动作落在真实关键词上。
- 重排过程中，关键标签保持所属对象，卡片显现后不相交。内容淡出、几何变形、内容回归各有明确阶段。
- 节点图、创作指令和画面预演标为概念示意；真实波形使用当前配音包络。使用自己的插画与标记，不把参考截图里的品牌和作品移入成片。
- 沿用已确认的音乐和轻动作音，口播时压低音乐；最终AAC检查-15～-14 LUFS、True Peak不高于-1dBTP。

## 本地编辑与验收

当前60秒样例的Studio入口：`PixelWorldPortrait`。分镜与横屏共用 `public/episodes/pixel-world/story.json`，音轨使用已确认的 `pixel-minute/mix.m4a`；竖屏图形在 `PixelWorldPortrait.tsx`，几何在 `pixelWorldPortrait.ts`。修改画幅几何时，把坐标放入共享状态供绘图和检查使用。

在template目录运行：

```bash
npm run verify
npx tsx scripts/check-pixel-world-portrait.ts
npm run export -- PixelWorldPortrait
```

完成条件：布局、类型和配置检查通过；检查每种场景及叙事重排的连续帧；实际MP4核对1080×1920、30fps、完整时长、完整解码和声音；用户观看并确认。当前60秒片应为1800帧。每次另存，保留已确认横屏与前版。

技术结果、手机检查和用户确认分别记录。横屏与竖屏成片均于2026-10-27获用户确认，可作为此风格的本地复用基准；手机发布界面的遮挡检查仍按发布场景执行。

连接图镜头从中央节点的近景起步，停留约 0.3 秒，再用约 1.4 秒拉回全图，随后留给观众读外围节点。横竖屏各用自己的节点中心，标题独立于镜头变换。镜头可沿用到其他同类连接图。
