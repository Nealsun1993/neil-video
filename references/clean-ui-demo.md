## 制作规则

- 大画面用纯白底（#FFFFFF），浅灰只用于浏览器内部控件。黑字和线性图标负责信息。品牌强调色主要给可点击控件、焦点和成功反馈。白色浮层靠投影、薄边和底页压暗分出层级。
- 先给整页，再向实际操作目标推近。推近、点击、界面更新分开读，点击时光标落在真实按钮范围内。落位后留出读字时间。
- 同一动作尽量让一个对象跨镜头接力。按钮接弹窗，配置行接对应功能，数据卡接移动端结果。承接时保持颜色、圆角或落点里至少一项连续。
- 源片有柔焦与浅色淡出，适合用在背景退场或章节切换。操作文字、光标和结果在阅读停留阶段保持清晰。
- 做成可复用模板时，优先拆为页面、浮层、按钮、光标、设备框、地址栏。每期替换截图、文字、品牌色和焦点锚点。竖屏优先把页面概览、操作特写、结果纵向重排。

## 口播工作流试片分镜

首条以「一段口播如何变成可发布的视频」为主题。下表为试片顺序，实际切点跟配音和界面动作确定。

| 镜头 | 画面与承接 |
| --- | --- |
| 导入 | 先给工作台整页。音频拖进导入区，文件卡落下后展开成波形与文稿。 |
| 校对 | 推近文稿里正在播放的一句。光标定位并改字，同一句同步更新到字幕预览。 |
| 配画面 | 从确认过的字幕句提取一个关键词，让词卡展开为对应的画面卡片，再把卡片落到时间轴上。 |
| 预览与导出 | 拉回工作台全景，播放一段有字幕和画面的视频预览。再从同一份内容切换到横屏、竖屏结果，最后显示实际的导出入口。 |

替换一期时，换音频波形、台词、画面卡片和预览片段即可。使用真实操作时以实际状态为准，概念画面标明「流程示意」。优先试「校对一句 → 字幕同步更新 → 预览」这组镜头，先确认点击落点和字幕变化读得清楚。

## 横屏校对试片

`CleanUiDemo` 是 13 秒、1920×1080、60fps 的无声视觉试片。约 0–1.8 秒为左对齐章节卡，1.7–3.6 秒为独立浏览器窗口，3.6–7.8 秒为底页压暗、弹窗与推近，7.3 秒应用改字并返回字幕预览，约 10.8 秒切到纯白品牌收尾。浏览器窗口标为「示意界面」。

本版按参考画面对齐留白、章节标签、蓝色按钮、黑白手形光标和弹窗层级。拉丁字用 Arial，中文用 MiSans，字重与字号按参考画面的比例调整。图标按参考轮廓用 SVG 重绘，口播文案使用工作台自己的示例。

Studio 选 `CleanUiDemo`。在 `template/` 下用 `npm run export -- CleanUiDemo` 导出。示例句的 `project`、`prefix`、`before`、`after`、`cue` 可用 `--props` 替换。当前按一行短句构图，换较长台词后需检查编辑框与预览字幕。

## 一分钟口播工作流

`CleanUiWorkflow` 为 60 秒横屏示意片，1920×1080、60fps，使用本地合成器乐和轻操作提示音。校对环节复用 `CleanUiDemo`。完整片与短试片可在 Studio 分别打开。

| 时间 | 内容 |
| --- | --- |
| 0–4 秒 | 品牌标识和声音、文稿、预览图标 |
| 4–15 秒 | 文件拖入，波形展开，识别文稿出现 |
| 15–26 秒 | 点击校对、推近编辑浮层，应用后看字幕更新 |
| 26–40 秒 | 从一句字幕提取关键词，卡片展开并落到画面轨 |
| 40–55 秒 | 横屏与竖屏结果预览，打开导出浮层并显示文件就绪 |
| 55–60 秒 | 回到纯白品牌页 |

在 `template/` 下运行 `npm run export -- CleanUiWorkflow`。可用 `--props` 更换 `fileName`、`keyword` 和校对短句字段。示例界面、波形和输出状态用于说明流程。真实产品演示应使用已验收的操作状态及画面。

## 一分钟竖屏版

`CleanUiWorkflowPortrait` 为 1080×1920、60fps，沿用一分钟横屏的分镜时间、短句参数和音轨。文稿、字幕预览和时间轴纵向排列，居中弹窗和点击位置按 9:16 重设。最终导出示意展示 1080×1920 文件。

Studio 选择 `CleanUiWorkflowPortrait`，或在 `template/` 下运行 `npm run export -- CleanUiWorkflowPortrait`。

## 字幕原位反馈

横竖屏校对镜头共用同一个改字效果。点击「应用更新」后，预览字幕在原字位交替显示旧字和新字，短暂蓝色强调仅覆盖改动文字。以这次改动为结果反馈，后续再拉回工作台全景。

点击后的结果聚焦参考 `1920x1080 (3).mp4` 约 0:42 的界面层级。编辑窗退场后，字幕预览面板推近，文稿和时间轴轻微失焦。保留改字原位高亮，再一起恢复到全景。横屏右栏向内放大，竖屏面板在原列内放大。

## 镜头版 `CleanUiLive`（2026-11-10）

对照参考片补上“景别变化”，原 `CleanUiWorkflow` 保留。60 秒、1920×1080、60fps，沿用同一份配乐和四个场景。

- 每个场景外套一层镜头：先全景，再推近到正在操作的位置，再拉回。导入跟着拖拽推到识别出的文稿；配画面推到被选中的关键词、展开的画面卡和时间轴；导出把“导出视频”按钮孤立放大后接弹窗。关键帧在 `template/src/kit/cleanLive.ts`，格式是 [场景内秒数, 放大倍数, 中心x, 中心y]。
- 开场品牌名之后，声音、文稿、画面三个线条图标逐个画出。
- 导出完成后界面退到白幕后，竖屏成片在手机里播放，横屏和竖屏两个规格标签向两侧散开。手机里的片源在 `template/public/clean-ui-workflow/media/`，不进 Git。
- 结尾品牌名之后是搜索框打字。搜索词在配置的 `search`，不放网址。
- `tests/clean-live.test.ts` 检查镜头不会推到画面外、每个场景至少三次推近、停留不过长。
- 导出：`npm run export -- CleanUiLive`；关键帧 `npx tsx scripts/check-clean-live.ts`。

### 配置与复用（2026-11-11）

示例文案、手机里的竖屏成片和搜索词在 `template/public/clean-ui-workflow/live.json`，换一期只改这一份：

- `sample`：项目名、文件名、字幕前半句 `prefix`、错字 `before` 和改字 `after`（字数要相同）、提示语 `cue`、配画面的关键词 `keyword`。
- `phone`：手机里播放的竖屏成片、从第几秒开始、片源时长、两个规格标签。`search`：结尾搜索框里打的字。
- 场景时间和镜头关键帧跟着配乐和界面位置走，固定在代码里，不在配置里。界面里的品牌名「口播工作台」和按钮文字也是固定的。配乐不用重做。
- `validateCleanLive` 会拦下：文案超出版面字数、错字和改字字数不同、竖屏成片不够长、文案里出现平台名或链接。
- 出片照 `references/出片步骤.md`。
