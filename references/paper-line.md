# 纸感排印 · 横屏

> **注**：本页为早期 33 秒纯音乐原版记录；日常按口播配音出片（`16:9` 横屏 + `3:4` `1080×1440` 竖屏主标准、跨平台内置字体、三脚架零晃动）请用模块化口播版 [paper-talk.md](paper-talk.md)。

状态：2026-11-10 第一版，待用户观看确认。入口 `PaperLine`，33 秒、1920×1080、60fps。参考用户提供的 `1080x1080 (1).mp4`，只借手法，句子、名牌和版式都是口播工作台自己的。

## 这套风格是什么

浅灰纸底，全片几乎只有一行字，花样都发生在这行字身上。

| 段落 | 画面 |
| --- | --- |
| 开场 | 几个带抖动纹理的小方块和分工名牌出现，随即让位给光标 |
| 一行字 | 一句口播随光标打出，镜头跟着向左滚。带样式的词打完后变成符合词义的样子：选区加声波、变粗、变细、拉开字距、像素块收成点阵、倾斜带一下模糊。每个词旁边有一枚分工名牌和细蓝线选框 |
| 名牌扑上来 | 镜头回到点阵词，全部名牌从四周涌向它 |
| 字墙 | 同一个词用各种字重、宽窄、字体、描边、反白铺满，整面墙带倾斜并缓慢横移 |
| 黑底海报 | 像素化的黑色涌进来；三行大字先极细，再逐行变极粗 |
| 蓝色海报块 | 一整块蓝色，三行字依次是粗体、描边、黑底反白 |
| 收尾 | 纸色把黑底吃掉，小方块聚成品牌标，品牌名打字，一行等宽小字 |

“点点”是用小字符铺出来的灰调：一行行 `· : - * o m g` 和配置里的中文字，越密的地方字符越重，整体是缓慢流动的波浪。“像素”用在点阵词、转场和小方块上。

## 配置与复用

全部内容在 `template/public/paper-line/line.json`：

- `line`：一行字的分段。带 `style` 的词会变形，可选 `voice`、`heavy`、`light`、`breathe`、`pixel`、`lean`，并且必须带一个 `tag`（分工名牌）。
- `roles`：名牌用的分工名；`wallWord`：字墙上的词；`poster`：黑底三行大字；`block`：蓝色海报块；`texture`：点点灰调里的中文字。
- `timing`：打字速度、变形停留和各段时长。段落时间由这些数自动推算，`validatePaperLine` 会拦下超长的句子、缺名牌的词和收尾被挤掉的情况。
- 配乐 `scripts/paper-line-music.py` 从同一份配置算出每个字的打字声和每个词的提示音，改完文案重新生成一次。

字体只用工程现有的 MiSans 可变字重、像素体、等宽体，加系统自带的宋体和楷体。宋体和楷体依赖本机系统字体，换电脑渲染前要确认有这两款。

## 复核与导出

- 关键帧：`npx tsx scripts/check-paper-line.ts`。
- 导出：`npm run export -- PaperLine`。
- 运动量对照：`python3 scripts/check-motion.py 成片.mp4 参考片.mp4`。前 10 秒是慢节奏的打字段，数值偏低是设计如此。
