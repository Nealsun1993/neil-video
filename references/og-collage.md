2026-11-02新增。依据官方安装的 `bs-linktree-style-og` v1.0.2（本地目录 `~/.agents/skills/bs-linktree-style-og`）。本技能原生交付静态16:9 OG分享图。本地已保存视觉样张，并另行实现原生分层横屏动效 `OgCollageLaunch`，24秒、1920×1080、30fps；新视频待用户确认。

## 视觉规则

- 层级：一组超大白色品牌字、一句短标题、一个围绕主题的拼贴视觉路径。正文在中心88%安全区域，缩略图仍需能读。
- 配色：深森林绿 #103F2D 承托白字，洋红 #D83087、橙 #FA743B、钴蓝 #2858D8 作大面积剪影与色块，浅暖薄荷 #DDE8CA 作底。
- 造型：原创匿名人物剪影、倾斜矩形、摄录与剪辑的抽象物件、叶片，平面叠压并允许装饰形状出画；字与主要人物保留边距。
- 文字和画面：本样张品牌“口播工作台”，标题“让表达，有画面。”；插画里的媒体面板是原创概念插画，不作为实际产品截图或功能实证。
- 图标使用简单线条几何，不把第三方商标、emoji或图标字体当装饰。参考设计语法，使用本产品的新构图和原创人物。

## 横屏动效样片

`OgCollageLaunch` 使用独立React/SVG图层重画人物剪影、叶片、媒体面板、三张图形卡与白字；保留同一色彩和拼贴语法。静态生成图仅作风格参考，没有把整张位图推拉当作分层动效。矢量插画为原创概念示意，不是实际产品录屏或功能证明。

六拍各4秒：一个想法／开口让故事发生／文字声音画面拼合／三种图形变化／让表达有画面／品牌落版。人物、叶片与媒体背景在全局时间中连续换位；主文字换拍前收起、下一拍再进入。卡片在16秒前完成退出，媒体图层在中段收至上方，让标题保持清楚。

- 配置：`template/public/episodes/og-collage/og.json`。
- 图层、图形、构图与时间：`template/src/templates/OgCollage.tsx`。
- 音乐：`template/scripts/og-music.py` 本地原创24秒/120 BPM器乐，无旁白、无付费生成调用；素材与来源说明在该期目录。
- 预览：Studio选择 `OgCollageLaunch`。
- 导出：在template运行 `npm run export -- OgCollageLaunch`，或双击“导出视频.command”选择16。
- 检查：`npm run verify`，关键帧 `npx tsx scripts/check-og.ts`。实际成片另做完整解码、时长帧数、音轨与接缝连续帧检查。

当前仅有横屏动效，未声明竖屏重排完成。新视频的完整主观观看、试听与用户确认仍待完成。静态封面与视频分别保留，动效实现使用当前Remotion工程，未运行HyperFrames CLI。
