# 动效规范（统一三脚架稳定铁律）

一句话：**每个动作都对应配音里的关键词；动作单向干脆到位后 100% 静止锁死，严禁任何无意义的晃动、微爬、过冲回弹或倒走镜头。**

## 统一动效铁律（横屏 `16:9` 与竖屏 `3:4` 全风格适用）

1. **三脚架锁死**：UI 窗口、对话卡片、标签、列表与底板在完成入场缓出后必须完全静止固定；打字跨行、列表显现、内嵌抽屉展开不得引起外框顶边跳动或整体漂移。
2. **严禁四类伪动态噪音**：
   - 严禁 `Math.sin / Math.cos` 周期上下漂浮或绕轨摇晃；
   - 严禁欠阻尼弹簧过冲回弹（如冲过 `1.04x` 又缩回 `1.0x`）；
   - 严禁 `1 + u * k` 持续线性微爬缩放或对角线慢漂（会导致 1px 边框与网格持续闪烁）；
   - 严禁推近后再反向退回的倒走镜头或多航点来回点头。
3. **重点强调规则**：讲到核心结论、按钮触发或关键证据时，**仅允许干脆、单向、无过冲回弹的定点放大并保持静止驻留**。

## 光标

只做三种有意义的动作：

| 动作 | 什么时候 |
|---|---|
| 点击 | 按钮、开关、勾选、标签、列表行 |
| 悬停滑过 | 沿着被聚光的那句话滑过去 |
| 拖拽 | 把文件拖进来 |

- 点击时光标缩一下，并出一圈蓝色涟漪。
- 默认开启悬停反馈、略带弧度的路径和点击前约 0.16 秒到位；按钮先亮起或抬起，再按下。开关刚开启时有短暂亮度变化。旧工程可用 `"motion": {"polish": false}` 关闭打磨。
- **动作之间停住不动，不做无意义的漂移或颤动。**
- **工作台路径由页面模板根据 props 算出**，仍需实际检查落点。scene 光标由配置给出坐标，必须对照关键帧核对。

## 相机与定点聚焦

说到关键模块或关键原文时，单向干脆地聚焦到目标区域并稳稳停住读字：

- 聚焦放大倍数控制在可读且不出画的安全区间（通常 `1.04x` 到 `1.28x`），严禁约 `3%` 以下毫无信息增益的微颤缩放。
- 推近采用单调无回弹缓出（约 `0.36–0.55` 秒），到位后**保持静止驻留**，不做推完又拉回原地的倒走运动，也不做镜头慢呼吸填时长。
- 可用 `zoom: false` 关闭推近；大纲全片完整展示一次，回大纲最多一次。

## 换页：优先承接

**承接** = 上一页里被点的、被说到的那个元素，直接长成下一页（0.55 秒，单调无回弹落位）。

- 旧页原地不动，旁边的内容在新页长大时淡掉，不留残影。
- 例：点模块行 → 行展开成浏览器页；原文卡片 → 长成能力清单；通知条 → 长成时间轴；时间轴面板 → 长成合成页。
- 找不到合适的元素时，才用默认方式：旧页淡出，新页干脆推入定格。
- **工作台内至少一半的换页优先承接。** scene 间默认退出再进入，暂不自动对象承接；详见 [scheme-d.md](scheme-d.md)。

写法：下一镜的 props 里加

```json
"carry": {"anchor": "item:0", "click": true}
```

`click: true` 表示光标先点一下这个元素，它随即长成新页；不写就直接长。各页可用的锚点见 `templates.md`。

窗口启动同理：会话第一镜写 `"launch": {"from": [x, y, w, h], "r": 22, "bg": "#CFE2F6"}`（画面坐标），窗口从这个区域单向无过冲地展开定格。

## 动作曲线：全部采用单调无过冲曲线

严禁使用带超调回弹的欠阻尼弹簧，统一使用干脆起步、平稳落定后严格恒等于终态的单调缓动（如 `cubic-bezier(0.22, 1, 0.36, 1)`）：

| 动作 | 曲线 | 时长 |
|---|---|---|
| 点击、开关、勾选、状态变化 | 快速到位（单调缓出，无回弹） | 约 0.22 秒 |
| 行、卡片、通知、主面板出现 | 单调无过冲缓出（到位即锁死静止） | 约 0.34–0.40 秒 |
| 定点聚焦放大 | 单调无回弹缓出，落定后静止保持 | 约 0.38–0.55 秒 |
| 承接变形 | 单调 S / expo 缓动，起步干脆、落位稳停 | 0.55 秒 |
| 标题、说明文字 | 平滑出现，不回弹、不微爬 | 约 0.30–0.38 秒 |

## 运动模糊

- 引擎目前只对 **工作台** 的承接、换页、镜头移动自动加 180° 快门运动模糊（6 次采样）。
- `orb` 球飞行和 `scene` 快速流入流出尚未接入自动模糊。若本期要求这些段落有模糊，需要补充实现或预渲染，不能把工作台开关当作全片覆盖。
- 静止帧不加，保持 1:1 像素锐利。
- 默认自动开启；不需要时在 episode.json 顶层写 `"motionBlur": false`。

## 时间锚点

- 每个 `at` 是配音里关键词的时间，从骨架的 `_words` 查。
- 关键词出现的那一刻，对应动作同时发生。
- 不手敲近似秒数：差零点几秒，观众就能感觉到「画面抢了」或「画面慢了」。
