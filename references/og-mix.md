# OG 拼贴 · 多配方背景动效

2026-11-02用户反馈原React组件可以保留、背景过于单调，并提供四套新OG技能。新增 `OgMixLaunch`：24秒、1920×1080、30fps，归入第五种OG拼贴风格；原 `OgCollageLaunch` 保留作对照。

## 设计组合

| 时间 | 视觉配方 | 本片实现 |
|---|---|---|
| 0–4秒 | Wise：荧光底、超大深字、极简图形 | 荧光绿大字与本产品的方框中心点标记，构图留白 |
| 4–8秒 | Spotify：饱和红场、耳机人物、白色大字 | 原创虚构创作者耳机肖像在右，讲述文案在左 |
| 8–12秒 | Nike：摄影与有机色带前后穿插 | 摄录创作者、粉/蓝/橙/米色动态色带，保留原文字/声音/画面React卡片 |
| 12–16秒 | Slack：双色深紫、桌面与手机叠层 | 白色作品展示框内放真实已有OG横屏与ASCII竖屏成片帧，非第三方界面 |
| 16–20秒 | 原Linktree语法：剪影、拼贴与大白字 | 保留矢量人物与叶片，改为曲线深绿底与粉/米分区，撤掉重复矩形底板 |
| 20–24秒 | 荧光底巨字收束 | 与开头同色回环，品牌、标题及自身标记落版 |

四个新技能均由官方Skillry CLI安装，版本均1.0.2，位于 `~/.agents/skills/bs-{spotify,nike,slack,wise}-style-og/`。读取各自SKILL.md与visual-system.md后提取语法，移用于用户的视频请求，不照搬源品牌身份、标志、活动或人物。它们本来是静态OG工作流，本片在现有React/Remotion中实现分层动画，未宣称运行HyperFrames CLI。

保留原24秒文案、原卡片组件与原创器乐，以便比较背景升级。所有背景都是分层图形、作品图和人物图层；切换使用0.65秒方向揭示，文字在背景之后进入。色带位于人物前、React卡片后，避免挡住卡片文字。首尾的极简荧光场提供呼吸与品牌回环，其余段落增加摄影、有机曲线、双色分区和层叠窗口。

## 源材与真实性

`template/public/og-mix/` 保存两张由内置图像工具各生成一次的原创匿名人物PNG，透明通道保留，完整提示词和source.json随附。人物是视觉示意，不是实际用户、客户评价或合作背书。未使用FAL、未请求API密钥。

桌面作品图来自原OG视频的10秒渲染帧；手机作品来自现有半调ASCII竖屏实际成片22.5秒帧。设备边框是通用展示容器，不声称新增手机应用界面或联动功能。未使用四个源品牌的标志、专有界面、人物或宣传语。

## 编辑与检查

- 入口：`OgMixLaunch`。导出 `npm run export -- OgMixLaunch`；导出菜单选17。
- 背景与场景：`template/src/templates/OgMix.tsx`。
- 卡片、矢量人物与叶片继续复用 `OgCollage.tsx`，原组件默认行为保留。
- 共用文案/配乐配置：`template/public/episodes/og-collage/og.json`。
- 关键帧：`npx tsx scripts/check-og-mix.ts`；基础检查 `npm run verify`。
- 逐片检查：完整解码、24秒/720帧、文字与作品图边界、音轨、五个切点连续帧。真实成片另存，原片保留。

本版为横屏效果样片，待用户观看确认；完整主观试听、平台实际遮挡及竖屏适配仍需分别验收。OG仍只计为一个风格，背景配方不是四种新增风格。

后续减少定制素材的新一期优先使用 [通用素材模板](og-template.md)；本带人物演示保留。
