# 蓝光模板展廊 · 横屏试片

> **注**：本页为早期固定配乐纯音乐宣传片记录；日常按口播配音出片（`16:9` 横屏 + `3:4` `1080×1440` 竖屏主标准、三脚架零晃动）请用模块化口播版 [blue-talk.md](blue-talk.md)。

参考用户提供的 `1920x1080 (2).mp4`，原片为 Bolt Templates 宣传片。将原片的蓝光底场、上下穿行卡片、模板墙、单卡推近和提示词换样式用于口播工作台。

| 时间 | 镜头 |
| --- | --- |
| 0–3 秒 | 上下两组各三张卡片在透视空间穿行，露出产品名 |
| 3–12 秒 | 六张卡片排成三列，单张口播封面缓慢放大到前景 |
| 12–16 秒 | 时间轴、配画面、成片预览三张卡依次落位 |
| 16–21 秒 | 短句过渡后，提示词打字并亮起操作按钮 |
| 21–25 秒 | 在编辑界面内将深蓝封面换成浅蓝章节卡 |
| 25–31 秒 | 短句与蓝光品牌页收尾 |

31 秒，1920×1080，60fps，配乐为本地合成。六类卡片使用 React 和 SVG 绘制，界面标明示意。横屏试片使用独立入口，在 `template/` 下运行 `npx remotion studio src/blue-gallery-preview.tsx`，选择 `BlueGalleryPromo`。

精简版将展廊、模板卡和换色示例统一在深蓝、浅蓝和白色范围内。背景光低速移动，其他卡片在单卡推近时降低透明度。

## 实片版 `BlueGalleryLive`（2026-11-09）

对照参考片重做，旧版 `BlueGalleryPromo` 保留。段落沿用原配乐分段，31 秒、1920×1080、60fps。

- 卡片全部是干净风格的真实成片片段，在卡内播放：简约工作台、连续叙事、纯白产品演示、虹彩产品演示。片源在 `template/public/blue-gallery/media/`，由成片目录复制，不进 Git；取点在配置里。
- 镜头一直在动：开场卡片上下穿行；模板墙整体横移推近，两次单卡浮到左侧、右侧大字逐字推焦淡入，单卡落定后继续漂移；光标点中后推到满屏，在卡里接着播放同一段；五种成片横排持续左移；提示词框边打字边推近；冲进编辑器，预览用带光边的擦除连换三种风格；收尾光从底部持续升起。
- 段落之间用光团扫过和推焦接，不淡出到空底；暗场在提示词前与收尾前各一次。
- 运动量检查：`python3 scripts/check-motion.py 成片.mp4 参考片.mp4`，每秒低于 1.0 视为几乎静止。数值只用于同类片之间比较节奏。
- 预览：`npx remotion studio src/blue-gallery-preview.tsx` 选 `BlueGalleryLive`；关键帧 `npx tsx scripts/check-blue-live.ts`。

### 配置与复用（2026-11-11）

全部文案、片源和每段用哪些卡片在 `template/public/blue-gallery/live.json`，换一期只改这一份：

- `brand`：品牌名。`sources`：片源文件和时长。`media`：卡片，写明用哪个片源、从第几秒开始、卡片名。
- `wall`：开场一行（`intro` 两个词夹着品牌名）、模板墙 8 张卡、2 张特写卡和各自两行大字。第二张特写卡就是之后推到满屏的那张。
- `formats`：横排标题和 5 张卡。`prompt`：提示标题、打字正文、按钮。`editor`：窗口名、3 种风格和对应卡片、2 个设置项。`outro`：收尾短句和大字。
- 段落时间跟着配乐走，固定在 `template/src/kit/blueLive.ts`，不在配置里。配乐不用重做。
- `validateBlueLive` 会拦下：文案超出版面字数、卡片数量不对、卡片或片源没登记、片源不够长、文案里出现平台名或链接。
- 出片照 `references/出片步骤.md`。
